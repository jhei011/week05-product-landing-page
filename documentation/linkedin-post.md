🚀 Week 5 – Client-Server Technologies

This week I designed and built a responsive Product Landing Page for **Gunting Master Barbershop**,
a local barbershop in Lumban, Laguna, Philippines, using Laravel, Tailwind CSS, and Blade Components.
Rather than a typical tech mockup, I based it on a real small business — transforming a real
barbershop's services, pricing, and brand identity into a modern, mobile-friendly landing page.

Along the way I focused on:
✂️ Component-based development — 9 reusable Blade Components (navbar, hero, feature cards,
   pricing cards, testimonial cards, button, product showcase, CTA, and footer) instead of repeated HTML
🎨 A custom Tailwind design system — an onyx/chalk/gold palette and Playfair Display + Inter
   typography pairing, so every section feels like one cohesive premium barbershop brand
📱 Full responsive design — tested and refined across desktop, tablet, and mobile breakpoints

Comparing my initial wireframe with the final polished interface really showed how much
thoughtful spacing, color, and component structure can improve both the look and the
maintainability of a UI.

**Reflection (2–3 sentences — personalize before posting):**
Building a component library for a real barbershop's landing page made it clear how much
repetition a "simple" marketing page has, and how much cleaner the code becomes once that
repetition is pulled into reusable Blade Components. It also pushed me to think about a real
business's actual needs — the right services, honest pricing, and a design that reflects the
barbershop's premium identity — rather than just filling in a generic template.
